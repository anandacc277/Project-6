# Project 6 - Version Control Infrastructure

## Objective

Track Terraform infrastructure changes using Git and GitHub.

## Project Overview

This project demonstrates how Infrastructure as Code (IaC) can be managed using version control. Terraform code is stored in a Git repository and changes are tracked through commits, branches, and pull requests.

## Tools Used

- Terraform
- Git
- GitHub
- VS Code

## Project Structure

```text
Project-6
│
├── main.tf
└── README.md
```

## Terraform Configuration

The project contains a simple Terraform configuration that creates a local file resource.

## Workflow

1. Create Terraform configuration.
2. Initialize Git repository.
3. Commit code to local repository.
4. Push Terraform code to GitHub.
5. Create a feature branch.
6. Make infrastructure changes.
7. Push changes to GitHub.
8. Raise a Pull Request.
9. Review and merge changes.

## Key Learning Outcomes

- Infrastructure as Code using Terraform
- Version control using Git
- GitHub repository management
- Branching strategy
- Pull Request workflow
- Change tracking and collaboration

## Deliverable

A GitHub Pull Request demonstrating how Terraform changes are reviewed before being merged into the main branch.
